Privacidad

Información básica sobre el tratamiento de datos de la web pública de Velytra.

Responsable

La web pública de Velytra se gestiona bajo la marca Velytra con correo de contacto velytra@onmedic.org.

Esta página informa del tratamiento básico de datos vinculado exclusivamente a la web pública y a los contactos recibidos por correo electrónico.

Datos que pueden tratarse

Los datos que podemos tratar son los que nos facilites voluntariamente cuando nos escribes, como tu nombre, correo electrónico, organización y el contenido del mensaje.

También pueden generarse datos técnicos mínimos propios del funcionamiento habitual de un sitio web estático, como la dirección IP o datos básicos de navegación a nivel de infraestructura.

  • Nombre y datos de contacto que nos envíes
  • Contenido del mensaje o consulta
  • Datos técnicos imprescindibles para servir la web

Finalidad

Utilizamos estos datos para responder consultas, gestionar comunicaciones relacionadas con Velytra y mantener la seguridad y disponibilidad básica de la web.

No se utilizan para elaborar perfiles comerciales ni para finalidades incompatibles con la consulta original.

Base jurídica

La base jurídica principal es el consentimiento implícito en el hecho de escribirnos y la necesidad de gestionar tu solicitud.

En los tratamientos técnicos mínimos de funcionamiento, la base puede ser el interés legítimo de mantener operativa la web.

Conservación y destinatarios

Los datos se conservarán durante el tiempo necesario para atender la consulta y, si es preciso, para mantener un registro básico de la relación.

No se cederán a terceros excepto cuando sea necesario por obligación legal o por el funcionamiento técnico de los servicios de alojamiento y correo.

Derechos

Puedes solicitar el acceso, rectificación, supresión, limitación u oposición al tratamiento de tus datos escribiendo a velytra@onmedic.org.

Si consideras que el tratamiento no es adecuado, también puedes presentar una reclamación ante la autoridad de control competente.

Velytra

Velytra conecta entrenamientos, analítica y seguimiento entre atleta y entrenador en un único entorno.

Para actualizaciones o colaboraciones, escríbenos a velytra@onmedic.org
